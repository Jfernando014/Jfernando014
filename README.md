### Proyectos Principales

#### [EDS Management (`GasStationManagment`)](https://github.com/Jfernando014/GasStationManagment)
*Rol: Líder Técnico, DevOps y Desarrollador Full-Stack*
Plataforma de gestión operativa y contable para estaciones de servicio (EDS): cierre diario en 6 pasos, conciliación de medios electrónicos (Credibanco, Redeban QR, Puntos Colombia), control de tanques de combustible, turnos e incentivos.
- **Stack:** Java 21 LTS, Spring Boot 3.2, Spring Modulith (Arquitectura Hexagonal + 8 módulos desacoplados con eventos de dominio), Spring Security (JWT/RBAC), Angular 21 PWA, PostgreSQL 16, Flyway (+40 migraciones), Docker Compose (`dev`/`ci`/`prod`), Testcontainers, JUnit 5 y GitHub Actions.

#### [PiedraAzul — Gestión Clínica](https://github.com/SimpleBucket/PiedraAzul)
*Rol: Co-Líder Full-Stack · 1.er puesto del curso Ingeniería de Software III (~38 estudiantes)*
Sistema de agendamiento médico y terapéutico multi-rol (autónomo para pacientes y manual para agendadores) con notificaciones en tiempo real y exportación de reportes.
- **Stack:** C#, .NET 10, Blazor WebAssembly, GraphQL, SignalR, Entity Framework Core 10, PostgreSQL 17 (AWS y Docker), Lucene.NET, ASP.NET Core Identity / Keycloak (MFA TOTP y Passkeys FIDO2), 113 pruebas unitarias (xUnit) y auditoría de seguridad con OWASP ZAP.

#### [JoyOS — Automotive IVI Launcher](https://github.com/Jfernando014/JoyOS)
*Rol: Creador y Desarrollador Principal · En uso real en vehículo*
Launcher automotriz e interfaz de telemetría para unidades principales Android, desacoplando servicios nativos de hardware en Kotlin de una capa visual acelerada por hardware vía `@JavascriptInterface`.
- **Stack:** Kotlin (Android SDK 34), Bluetooth Classic SPP / BLE GATT (telemetría OBD-II ELM327), decodificación USB-Serial 433.92 MHz (sensores TPMS), motor de audio DSP nativo (EQ 5 bandas, BassBoost), GPS + mapas Leaflet offline, y actualizaciones OTA con Gradle y GitHub Actions.

#### [ComandasApp](https://github.com/Jfernando014/ComandasApp)

Sistema de gestión de comandas en tiempo real para sincronizar pedidos entre meseros, cocina y caja.
- **Stack:** C#, .NET 10, Clean Architecture / DDD, MediatR (CQRS), HotChocolate GraphQL, Blazor WebAssembly, SignalR, Entity Framework Core 10, PostgreSQL y Docker.
